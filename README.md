# 🪨📄✂️ Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors** game built using **Python**. The player competes against the computer, which randomly selects Rock, Paper, or Scissors. The game keeps track of both scores and allows the player to play multiple rounds.

## 🎮 Features

* 👤 Enter your name
* 🪨 Choose Rock
* 📄 Choose Paper
* ✂️ Choose Scissors
* 🤖 Computer makes a random choice
* 🏆 Automatically determines the winner
* 📊 Tracks player and computer scores
* 🔄 Play multiple rounds
* 🚪 Exit the game anytime

## 🛠️ Technologies Used

* **Python 3**
* **Random Module**

## 🎯 How to Play

1. Enter your name.
2. Select an option:

   * `1` → Rock
   * `2` → Paper
   * `3` → Scissors
   * `4` → Exit
3. The computer randomly selects its choice.
4. The winner is displayed.
5. Scores are updated after each round.

## 🏆 Game Rules

| Player      | Computer    | Result      |
| ----------- | ----------- | ----------- |
| Rock 🪨     | Scissors ✂️ | Player Wins |
| Paper 📄    | Rock 🪨     | Player Wins |
| Scissors ✂️ | Paper 📄    | Player Wins |
| Same Choice | Same Choice | Draw        |
